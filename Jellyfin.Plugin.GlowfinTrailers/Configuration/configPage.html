Glowfin Trailers

Fetches a movie's or show's online trailer (its YouTube trailer link) onto this server the first time someone presses Play Trailer in Glowfin, then keeps a copy so it starts straight away next time. Trailer files you saved next to your media are always used first.

This uses yt-dlp, which downloads from YouTube. That goes against YouTube's terms of service; enable this plugin only if you accept that for your own server.

Leave empty to let the plugin download and update yt-dlp itself.
When full, the trailers played longest ago are deleted.
